# EdgeRun App Package Contract

This repository owns the app build path. A user-authored app package is a
directory with explicit source, manifest intent, generated output, and object
identity inputs.

Canonical layout:

```text
app/
  app.c
  app.manifest
  assets/
  .build/
    app.wasm
```

Rules:

- `app.c` is the authored source for the admitted EdgeRun C subset.
- `app.manifest` records the app contract, source object hash, asset object
  hashes, required memory pages, and allowed host imports.
- `assets/` contains source assets only. Generated packed assets belong under
  `.build/`.
- `.build/app.wasm` is generated by `tools/wasm-compile` and must stay
  untracked.
- WAT files are low-level fixtures for runtime/compiler tests, not the normal
  app authoring format.
- Package admission must use content identity from the manifest and generated
  Wasm bytes. Labels and paths are not authority.

Initial C subset:

```c
extern i64 ui_emit(i64, i64) __import("edgerun.ui", "emit");
memory(1);
export i64 main(void) { return 7; }
```

Unsupported C syntax is fatal. The subset grows only when compiler output,
runtime validation, and tests are updated together.
