# Drivers and Firmware: The Hidden Software Under the Software

Not all software is visible.

Drivers let the operating system talk to hardware. Firmware is small software running inside devices and chips.

## Where hidden software lives

Firmware can run inside:

- Wi-Fi chips
- Bluetooth chips
- cellular modems
- SSD controllers
- camera controllers
- GPUs
- secure elements
- TPMs

Drivers translate between the OS and those devices. Firmware often runs below the level ordinary users can inspect.

## Main lesson

Your device contains computers inside the computer, and you do not control all of them.

## Edgerun seed

A realistic user-owned system must admit hardware trust boundaries. Some parts can be made explicit and measured. Some parts remain opaque and must be isolated.
