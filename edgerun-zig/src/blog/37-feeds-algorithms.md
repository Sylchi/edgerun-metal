# The Feed Is Not A Window. It Is A Steering Wheel.

When the feed chooses what you see, it also trains what you become.

Feeds are not neutral lists. They rank, delay, amplify, suppress, and repeat. Engagement systems learn which emotions keep people watching and then optimize for those signals.

> Mental model: a feed is a steering system, not a window.

## The loop

```text
watch
  -> measure
  -> rank
  -> recommend
  -> react
  -> measure again
```

Outrage, fear, attraction, envy, and tribal conflict can all become optimization targets.

The dangerous part is not that ranking exists. Ranking is necessary when there is too much to read. The dangerous part is hiding the objective.

## Different objective, different life

The same posts can produce different days:

- maximize time spent: show whatever keeps the user scrolling
- maximize anger: show conflict and humiliation
- maximize local friends: show people the user actually knows
- maximize learning: sequence ideas from simple to hard
- maximize creator support: show work from people the user chose
- maximize calm: suppress repeated outrage loops

An algorithm is not just math. It is a policy about what kind of person the system wants the user to become.

## What users should see

A feed should expose:

- why this item appeared
- which objective ranked it
- which source supplied it
- which rule suppressed something else
- whether paid placement was involved
- how to switch rankers

Without that, the user is not choosing a feed. The feed is choosing the user.
